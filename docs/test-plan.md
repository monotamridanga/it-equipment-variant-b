# 5. План проверок

1. Создание пустой базы: статистика показывает 0 записей (NFR-01).
2. Добавление карточки и просмотр: все обязательные реквизиты сохранены (FR-01, FR-03).
3. Повторный инвентарный и серийный номер: сообщение об ошибке (FR-01).
4. Выдача компьютера: статус `in_use`, сотрудник и кабинет сохранены (FR-04).
5. Списание: статус `retired` и отказ при новой выдаче (FR-05).
6. Групповая статистика: суммы соответствуют количеству карточек (FR-06).
7. История действий: последовательность регистрации и выдачи (FR-07).
8. CLI: команда `add` и затем `stats` работает через одну БД (интеграционная проверка).

Запуск: `python -m unittest discover -s tests -v`. Набор тестов воспроизводим и использует временную SQLite-базу.
