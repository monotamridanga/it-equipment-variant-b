# 6. Развёртывание и эксплуатация

1. Установить Python 3.10 или новее.
2. Скопировать каталог репозитория на компьютер администратора.
3. Выполнить `python equipment.py --db inventory.sqlite3 init`.
4. Внести оборудование посредством `add`.
5. Для проверки использовать `list`, `history`, `stats`.
6. Сделать резервную копию файла `inventory.sqlite3` после завершения операций программы.

База не включается в Git (правило `*.sqlite3` в `.gitignore`). Не размещать персональные данные работников и реальный реестр оборудования в публичном репозитории.
