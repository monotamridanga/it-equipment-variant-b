# 4. Роли участников и предлагаемые права GitHub

- **Владелец / руководитель проекта (Admin)** — управление репозиторием, настройками безопасности и участниками.
- **Технический руководитель (Maintain)** — организация веток, ревью и релизов; без передачи права смены владельца.
- **Разработчик (Write)** — коммиты в рабочие ветки и pull request; прямое изменение защищённой `main` запрещается правилами.
- **Тестировщик (Triage/Read)** — чтение кода, заведение и сортировка ошибок; Triage даёт работу с issues без записи в код.
- **Заказчик / наблюдатель (Read)** — просмотр репозитория и результатов тестирования.

**Планируемые правила**: запрет прямого push в `main`, обязательная проверка тестов и хотя бы одно одобрение pull request до слияния, запрет force-push и удаления `main`. Эти настройки предложены, но в личном GitHub пока не применены.

В публичном репозитории исходный код доступен всем на чтение, даже тем, кому не назначена роль; разграничивается право внесения изменений. Роли GitHub здесь не являются ролями конечных пользователей программы.
