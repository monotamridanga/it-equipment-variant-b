# 3. Иерархическая структура работ (ИСР)

1. **Анализ и планирование**
   1.1. Исследование проблемы, определение пользователей.
   1.2. Формулирование требований FR-01—FR-07, NFR-01—NFR-04.
   1.3. Разработка критериев приёмки.
2. **Документирование и проектирование**
   2.1. Составление технического задания.
   2.2. Проектирование таблиц оборудования и событий.
   2.3. Проектирование команд CLI и состояний.
3. **Реализация**
   3.1. Создание и миграция схемы SQLite.
   3.2. Создание карточки, просмотр, поиск и статистика.
   3.3. Выдача, списание и журнал действий.
4. **Проверка качества**
   4.1. Модульные тесты.
   4.2. Интеграционная проверка CLI—SQLite.
   4.3. Проверка приёмочных требований.
5. **Развёртывание**
   5.1. Инструкция установки и запуска.
   5.2. Подготовка демонстрационной БД.
6. **Сопровождение**
   6.1. План резервного копирования и проверки целостности.
   6.2. Регламент регистрации ошибок.

Каждому верхнему уровню ИСР соответствует ветвь `phase/01-requirements`—`phase/06-support`; интеграция результатов выполняется в `main`.
