# 1. Требования и назначение

## Предпосылки

Учёт устройств при помощи разрозненных таблиц затрудняет определение расположения компьютера, ответственного сотрудника и истории перемещений. Учебный продукт предлагает единый журнал инвентарных единиц.

## Целевая аудитория

Оператор учёта (ввод карточек), системный администратор (выдача и списание), руководитель ИТ (сводные показатели).

## Функциональные требования

FR-01. Регистрация оборудования с полями: уникальный инвентарный номер, тип, модель, серийный номер, кабинет, состояние.
FR-02. Просмотр всего перечня с фильтром по состоянию.
FR-03. Просмотр карточки по инвентарному номеру.
FR-04. Выдача оборудования ответственному лицу с обновлением местонахождения.
FR-05. Списание оборудования без возможности повторной выдачи.
FR-06. Формирование сводной статистики по состояниям.
FR-07. Просмотр журнала действий по каждой единице.

## Нефункциональные требования

NFR-01. Локальная работа без сети на Python 3.10+ и SQLite.
NFR-02. Корректные сообщения об ошибках при некорректных данных.
NFR-03. Ввод и вывод в UTF-8.
NFR-04. Автоматические модульные тесты основных переходов состояний.

## Ограничения и критерии приёмки

Это учебный прототип, не промышленная CMDB: не реализованы графический интерфейс, многопользовательский сервер, резервное копирование по расписанию и пользовательские учётные записи. Приёмка проводится по успешному запуску CLI и тестов, корректности контроля уникальности, запрету выдачи списанного оборудования.
