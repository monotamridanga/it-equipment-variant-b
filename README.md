# Учёт компьютерной техники в организации

Учебный проект для рейтинговой работы по дисциплине «Проектная деятельность в ИТ», вариант для фамилии на букву «Б». Консольная программа `equipment.py` реализует учёт единиц оборудования в локальной базе данных SQLite без внешних зависимостей.

## Требования

- Python 3.10 или новее; Git для просмотра истории версий.
- Сетевая связь для работы программы не требуется.

## Быстрый запуск

```bash
python equipment.py --db inventory.sqlite3 init
python equipment.py --db inventory.sqlite3 add --tag PC-001 --kind desktop --model 'Dell OptiPlex' --serial SN-001 --location 'Кабинет 12'
python equipment.py --db inventory.sqlite3 list
python equipment.py --db inventory.sqlite3 assign PC-001 --person 'Иван Петров' --location 'Кабинет 15'
python equipment.py --db inventory.sqlite3 history PC-001
python equipment.py --db inventory.sqlite3 stats
python -m unittest discover -s tests -v
```

Используйте команду `python equipment.py --help` для просмотра всех операций. Аргумент `--db` указывает путь к локальной базе данных (по умолчанию `inventory.sqlite3`).

## Бизнес-правила

- Инвентарный номер и серийный номер уникальны (серийный номер может быть не указан).
- Допустимые состояния: `in_stock` («на складе»), `in_use` («эксплуатируется»), `retired` («списано»).
- Списанное оборудование нельзя выдать сотруднику повторно.
- Выдача регистрирует сотрудника и новое местонахождение; список операций записывается в журнал.
- Демонстрационный проект не реализует аутентификацию и сетевой доступ: разграничение прав GitHub относится к совместной разработке, а не к правам пользователей данной локальной CLI-программы.
