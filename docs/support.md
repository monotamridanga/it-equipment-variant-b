# 7. Сопровождение

- Ошибки оформляются в Issues со сценарием воспроизведения, фактическим и ожидаемым результатом.
- Изменения выполняются отдельными ветками и вливаются после тестов и проверки ревьюером.
- Для восстановления данных используются резервные копии SQLite, которые необходимо хранить отдельно от Git.
- Ежемесячная проверка включает запуск тестов, сверку реестра и контроль времени последней резервной копии.
- В план расширения входят GUI, учёт подразделений, импорт/экспорт CSV, разграничение прав конечных пользователей и журнал аутентификации.
